# 📖 Conteúdo

## 1️⃣ Databricks Lakehouse Platform

Introdução à plataforma Databricks.

Principais tópicos:

- Criação de Clusters
- Notebooks
- Delta Lake
- Bancos de Dados
- Tabelas
- Views

---

## 2️⃣ ELT with Spark SQL and Python

Processamento de dados utilizando Spark SQL e PySpark.

Principais tópicos:

- Querying Files
- Writing Tables
- Advanced Transformations
- Higher Order Functions
- SQL UDF
- PySpark

---

## 3️⃣ Incremental Data Processing

Processamento incremental utilizando recursos do Spark.

Principais tópicos:

- Structured Streaming
- Auto Loader
- Multi-Hop Architecture

---

## 4️⃣ Production Pipelines

Construção de pipelines para produção.

Principais tópicos:

- Bronze Layer
- Silver Layer
- Gold Layer
- Jobs
- Pipelines

---

## 5️⃣ Data Governance

Governança e segurança dos dados.

Principais tópicos:

- Permissions
- Fine-Grained Access Control
